# บันทึก Recheck ข้อมูลและตารางเบี้ย

เอกสารภายในสำหรับผู้ดูแลเว็บและตัวแทน ไม่ใช่เนื้อหาสำหรับลูกค้า

เดิมข้อความชุดนี้แสดงอยู่บนหน้า `/plans` ซึ่งลูกค้าเห็นได้ ทำให้ลูกค้าอ่านเจอประโยคอย่าง
"ไม่ควรใช้ตัวเลขนี้ปิดการขาย" และ "ควรตรวจใบเสนอราคาจริงซ้ำ" แล้วสรุปว่าเบี้ยทั้งเว็บเชื่อไม่ได้
จึงย้ายมาเก็บที่นี่ และเพิ่มเทสต์กันไม่ให้ย้ายกลับเข้า `index.html` อีก

## หลักการคำนวณในตารางสะสม

- ตารางเบี้ยยึดตามแหล่งข้อมูลอย่างเป็นทางการที่ได้รับมาเป็นหลัก และคำนวณแบบรายปีตามอายุที่เพิ่มขึ้นของผู้เอาประกัน
- ตัดแถวอายุ 99 ออกจากตารางสะสมแล้ว เพราะเบี้ยอายุ 98 คือปีกรมธรรม์ที่คุ้มครองไปจนถึงปีที่จะอายุ 99 ก่อนสิ้นสุดความคุ้มครอง

## จุดที่ต้องตรวจใบเสนอราคาจริงซ้ำก่อนใช้ปิดการขาย

- **OPD เหมาจ่าย** เพศชาย วงเงิน 30,000 บาท ช่วงอายุ 81-90 ต่ำกว่าช่วง 76-80 มากผิดปกติ
  ห้ามใช้ตัวเลขนี้ปิดการขายโดยไม่เช็ก NST หรือใบเสนอราคาจริง
- **Elite Health Plus** แหล่งข้อมูลสาธารณะแสดงตารางเบี้ยถึงอายุรับทำใหม่ 90 ปี
  แต่ผลิตภัณฑ์ต่ออายุได้ถึง 99 ปี เบี้ยช่วงหลังอายุ 90 ต้องตรวจจากใบเสนอจริงก่อนใช้ประกอบการตัดสินใจ

## ข้อตกลงเชิง logic ที่เลือกไว้

- **D Care** มี 2 แนวทางคือ ระยะเริ่มต้น+รุนแรง และเฉพาะระยะรุนแรง
  เครื่องมือใช้โหมดระยะเริ่มต้น+รุนแรงเป็นค่าตั้งต้น เพราะเหมาะกับการวางแผนโรคร้ายแรงทั่วไปมากกว่า
- **HB (ชดเชยรายวัน)** เบี้ยคงที่ตลอดสัญญา ยึดอายุแรกที่สมัคร ไม่ปรับเพิ่มทุกปีตามอายุเหมือนสุขภาพเหมาจ่าย
- **PA Easy Plan** อายุรับและต่ออายุถึง 85 ปี แสดงตารางตามช่วงอายุของแผน

## กติกาสำหรับคนแก้ไขต่อ

- ห้ามนำเนื้อหาในไฟล์นี้กลับไปแสดงบนหน้าเว็บที่ลูกค้าเห็น
- ถ้าพบจุดน่าสงสัยใหม่ในตารางเบี้ย ให้บันทึกไว้ที่นี่ พร้อมวันที่ตรวจและแหล่งที่ใช้ยืนยัน
- ถ้าจุดไหนได้รับการยืนยันจากใบเสนอราคาจริงแล้ว ให้ย้ายออกจากหัวข้อ "ต้องตรวจซ้ำ" และระบุว่ายืนยันเมื่อไร
